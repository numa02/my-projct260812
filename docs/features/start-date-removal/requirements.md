# 要件定義: 起算日の廃止

`docs/requirements.md` F4(時間割マスタ設定)・F5(週次時間割の閲覧・編集)を変更する。起算日(週番号「第N週」を数える基準日)の設定を廃止し、週次時間割は日付範囲のみで週を表す。

## 背景

起算日は「第N週」の表示にしか使われておらず、メモ・週次の個別変更などの保存データはすべて日付(`note_date`・`week_start_date`)で管理されている。一方で、起算日を設定しないと週次時間割画面が開けない、授業記録開始後は「年度を更新する」操作を経ないと変更できない、といった手間が教員側に発生していた。

## 機能概要

1. 時間割マスタ設定画面から、起算日の入力欄・未入力エラー・読み取り専用表示・「年度を更新する」操作と確認ダイアログを削除する
2. 週次時間割画面は、起算日の有無に関わらず常に表示できるようにする(起算日未設定時の「参照不可」状態を廃止)
3. 週次時間割画面の週表示から「第N週」を削除し、日付範囲(例:「2026年4月6日(月)〜4月10日(金)」)のみを表示する

## ユーザーストーリー

1. 教員として、サインアップ直後から週次時間割を開きたい。それは起算日という本来不要な設定を先に済ませる手間を省くためだ。
2. 教員として、年度が変わっても起算日の再設定を意識せずに使い続けたい。それは年度替わりの作業を減らすためだ。

## 機能要件

- Given: 時間割マスタ設定画面を開いている
  When: 画面が表示される
  Then: 起算日の入力欄・「年度を更新する」ボタンは表示されない。マスの割当だけを入力して保存できる

- Given: 時間割マスタを一度も保存していない(サインアップ直後など)
  When: 週次時間割画面を開く
  Then: 今週(JSTで今日を含む月曜始まりの週)の日付範囲と、全マス未設定の時間割が表示される。時間割マスタ設定画面へ誘導する空状態は表示されない

- Given: 週次時間割画面を開いている
  When: 週送り・週指定で週を切り替える
  Then: 見出しには「yyyy年M月d日(月)〜M月d日(金)」形式の日付範囲のみが表示され、「第N週」は表示されない

- Given: 過去に起算日を設定していた教員
  When: 本改修のリリース後に各画面を開く
  Then: 保存済みの起算日はどの画面にも表示されず、動作にも影響しない。メモ・週次の個別変更・所見などのデータは変わらない

## 非機能要件

- 日付計算(今日を含む週の月曜日の判定)は従来どおりJST固定で行う
- データ移行は発生しない(保存データは日付で管理されているため)

## スコープ外

- 学期・年度の概念を新たに持たせること
- 週次時間割以外の画面(授業記録・生徒別メモ一覧・所見管理)の日付表示の変更

## 用語

| 用語 | 説明 |
|---|---|
| 起算日(廃止) | 旧仕様で週番号「第N週」を数える基準としていた日付。本改修で廃止 |
