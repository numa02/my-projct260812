## 最低限のテスト(P0)

## TC-001: 実行前に個人情報を含む旨の確認画面が表示され、キャンセルするとダウンロードされない

- 優先度: P0
- 種別: UI
- 観点: 異常系
- 自動テスト: `e2e/settings-export.spec.ts`

### 前提条件
- `/settings/export` を開いている

### 操作手順
1. 「全データをエクスポート」を実行する
2. 確認ダイアログでキャンセルする

### 期待結果
- 「ダウンロードされるファイルには生徒の氏名など個人情報がそのまま含まれます。ファイルの保管・取り扱いには十分注意してください」の注意文が表示される
- キャンセルするとダイアログが閉じ、ダウンロードは行われない

### 確認した環境
- [ ] Chrome (Mac)

---

## TC-002: 確認後に実行すると、生徒ごとにメモ・所感がまとまったJSONがダウンロードされ、APIキー設定は含まれない

- 優先度: P0
- 種別: セキュリティ
- 観点: 正常系
- 自動テスト: `e2e/settings-export.spec.ts`(ダウンロードされたファイルの中身まで検証)

### 前提条件
- クラス・生徒等のデータとAIプロバイダのAPIキーを登録済み

### 操作手順
1. 「全データをエクスポート」→確認ダイアログで続行する

### 期待結果
- JSONファイルがダウンロードされる
- クラス・生徒・科目・時間割・メモ・所感・プロンプトひな形が生徒ごとにまとまった形で含まれる
- AIプロバイダ設定(APIキーを含む)は一切含まれない

### 確認した環境
- [ ] Chrome (Mac)
