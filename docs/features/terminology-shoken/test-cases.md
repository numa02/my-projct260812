# テストケース: 用語「所感」を「所見」に統一する

## 最低限のテスト(P0)

### TS-P0-01 画面に旧表記「所感」が残っていない

- 前提: ログイン済み、クラス・生徒・共有メモが1件以上ある
- 手順: サイドナビゲーション、所見管理画面(AI生成・保存・上書き確認・エラー表示)、生徒名簿の削除確認ダイアログ、プロンプトひな形編集画面、データエクスポート画面を順に表示する
- 期待結果: どの画面にも「所感」の表記がなく、「所見」と表示される
- [ ] Chrome (Mac)

### TS-P0-02 既定プロンプトひな形が新表記になっている

- 前提: プロンプトひな形を一度も保存していない
- 手順: プロンプトひな形編集画面を開く
- 期待結果: 既定ひな形に「所見文を作成してください」と表示される
- [ ] Chrome (Mac)

## 後で確認するテスト(P1)

### TS-P1-01 保存済みひな形は書き換わらない

- 前提: 旧表記「所感文」を含むひな形を保存済み
- 手順: プロンプトひな形編集画面を開く
- 期待結果: 保存済みの内容がそのまま表示される(自動で書き換わらない)
- [ ] Chrome (Mac)
