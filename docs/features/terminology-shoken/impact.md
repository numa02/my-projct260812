# 影響範囲: 用語「所感」を「所見」に統一する

## 既存機能への影響

| 機能 | 影響 |
|---|---|
| 所見管理(旧 所感管理)画面 | 見出し・ボタン・トースト・確認ダイアログの文言が変わる。挙動の変更なし |
| サイドナビゲーション | 「所感管理」→「所見管理」 |
| プロンプトひな形編集 | 既定ひな形の文言が「所見文」になる。保存済みひな形は変わらない |
| AI生成(Hono) | 500エラー時のメッセージ文言のみ変わる |
| 生徒名簿・生徒削除 | 削除確認ダイアログ内の「メモ・所感」表記が変わる |
| データエクスポート | 画面の説明文のみ。JSONのキー(`comments`)は変わらない |
| 認証画面 | ツール名「週間時間割・生徒メモ・所見自動生成ツール」 |

## データへの影響

なし(DBスキーマ・保存データの変更なし)。

## テストへの影響

`design.md`「影響を受ける既存テスト」を参照。文言ベースのアサーションは置換で同時に追従する。

## ドキュメントへの影響

`docs/`配下全体、`mockups/`全画面、`CLAUDE.md`、`.claude/skills/feature-change/SKILL.md`の表記が変わる。適用済みマイグレーションのSQLコメントは旧表記のまま残る。
