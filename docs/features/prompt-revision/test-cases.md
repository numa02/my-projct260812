# テストケース: 所見プロンプトの差し替えと学年の反映

対応する要件は`docs/features/prompt-revision/requirements.md`。プロンプトひな形編集画面・所見管理画面の既存ケースは各画面のテストケース表側でも更新しており、ここでは本改修に固有のケースを扱う。

## 最低限のテスト(P0)

### PT-P0-01 未保存の教員には新しい初期値が表示される

- 優先度: P0
- 自動テスト: `e2e/settings-prompt-template.spec.ts`
- 前提: ひな形を一度も保存していないアカウントでログイン
- 手順: `/settings/prompt-template`を開き、学習の所見用・生活の所見用の両方を確認する
- 期待結果: いずれも新しい長文のひな形が表示される。`{{grade}}`・`{{targetCharCount}}`・`{{memos}}`が含まれ、「学期」の行は含まれない。プレースホルダーの案内文に`{{grade}}`(学年)がある

### PT-P0-02 保存済みのひな形は初期値の差し替えで上書きされない

- 優先度: P0
- 自動テスト: 未対応(手動確認)
- 前提: 本改修の反映**前**に自分でひな形を編集・保存していたアカウント
- 手順: 本改修の反映後に`/settings/prompt-template`を開く
- 期待結果: 自分が保存した内容がそのまま表示される。新しい初期値で上書きされていない。初期値に戻したい場合は、教員が手動で貼り替える必要がある(自動では戻らない)

### PT-P0-03 学年欄にクラスの学年が自動で入る

- 優先度: P0
- 自動テスト: `e2e/comments-class.spec.ts`
- 前提: 学年「3」のクラスに生徒が登録済みで、対象期間内に共有区分「共有する」のメモがある
- 手順: 所見管理画面で対象期間を指定し、生徒の行の「AIで生成する」を開く
- 期待結果: 「学年」欄に「3」が入っている。表示されるプロンプトに「学年：3」が含まれる

### PT-P0-04 学年を書き換えるとプロンプトに反映される

- 優先度: P0
- 自動テスト: `e2e/comments-class.spec.ts`
- 手順: AI生成セクションの「学年」欄を「特支」に書き換える → 続けて空欄にする
- 期待結果: プロンプトが「学年：特支」に変わる。空欄にすると「学年：指定なし」になる。クラス管理画面のクラスの学年は変わっていない

### PT-P0-05 クラスを切り替えると学年欄が切り替え後のクラスの学年になる

- 優先度: P0
- 自動テスト: 未対応(手動確認)
- 前提: 学年の異なる2クラス(例: 1年と3年)にそれぞれ生徒が登録済み
- 手順: 1年のクラスで生徒の行の学年欄を確認 → クラス選択を3年のクラスに切り替え、対象期間を指定して生徒の行を開く
- 期待結果: 学年欄が「3」になっている。前のクラスで書き換えた値や入力途中の所見文が残っていない

### PT-P0-06 プロンプトの冒頭で仮名コードを目視確認できる

- 優先度: P0
- 自動テスト: `e2e/comments-class.spec.ts`
- 手順: ひな形を編集していない状態で、AI生成セクションの「プロンプトを作成」を選びプロンプトを確認する
- 期待結果: 【入力情報】の先頭に「対象の児童・生徒：1-01-01」の形で仮名コードが表示され、**生徒の実名は含まれない**。教員が外部AIへ貼り付ける前に、個人名を出していないことをその場で確認できる(F12)

## 後で確認するテスト(P1〜P3)

### PT-P1-01 生成結果がメモにない事実を含まないこと

- 優先度: P1
- 自動テスト: 未対応(手動確認。AIの出力内容の確認のため自動化しない)
- 前提: APIキー設定済み。1件だけ短いメモ(例: 「理科：観察できてる」)がある生徒
- 手順: その生徒でAI直接生成を実行する
- 期待結果: 記録された範囲を超える内容(友達との関わり、感情、成長など)が書かれていない。新しいひな形の「事実に関する最重要ルール」が効いていることを確認する。期待どおりでない場合は、ひな形の調整で対応する(実装の不具合ではない)

### PT-P1-02 学年に応じて表現が変わること

- 優先度: P1
- 自動テスト: 未対応(手動確認)
- 手順: 同じメモに対し、学年欄を「1」と「6」に変えてそれぞれ生成する
- 期待結果: 低学年ではできたことが平易に、高学年では考え方・工夫・振り返りなどに触れた表現になる(メモに根拠がある範囲で)

### PT-P2-01 ひな形から`{{grade}}`を削っても生成できる

- 優先度: P2
- 自動テスト: `shared/prompt-builder.test.ts`(ロジック)。画面からの確認は手動
- 手順: ひな形編集画面で`{{grade}}`を含まないひな形を保存し、AI生成セクションでプロンプトを表示する
- 期待結果: エラーにならず、`{{grade}}`が無いまま他のプレースホルダーだけが置換されたプロンプトが表示される

### PT-P2-02 長いひな形でも編集欄が扱いやすいこと

- 優先度: P2
- 自動テスト: 未対応(手動確認)
- 手順: タブレット幅でひな形編集画面を開く
- 期待結果: 長文の初期値がテキストエリア内でスクロールでき、保存ボタン・案内文が隠れない
