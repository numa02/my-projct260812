# 要件: 所見プロンプトの差し替えと学年の反映

## 機能概要

所見生成に使うプロンプトのひな形を、教員が用意した新しい文面に差し替える。あわせて、プロンプトに学年を埋め込めるようにする。

1. 学習の所見用・生活の所見用のひな形の**初期値**を新しい文面に差し替える(`shared/prompt-builder.ts`)
2. プロンプトのプレースホルダーに`{{grade}}`(学年)を追加し、対象クラスの学年を自動で埋める。教員が必要に応じて上書きできる入力欄も設ける

新しい文面は、所見の観点(学習面は「知識・技能」「思考・判断・表現」「主体的に学習に取り組む態度」に対応する具体的な姿、生活面は係・当番・行事・友人との関わりなど)を列挙し、**メモに書かれていない事実を推測して書かせない**ことを最重要ルールとして明示するものになっている。従来の初期値(3行程度の簡易な指示)を置き換える。

## ユーザーストーリー

1. 教員として、AIに所見を書かせたときにメモにない内容を勝手に付け足されないようにしたい。それは通知表に載る文章であり、観察していない事実が書かれると使えないためだ。
2. 教員として、学年に合った表現で所見を生成したい。それは低学年と高学年で、書くべき内容(具体的にできたこと/考え方・工夫・主体性)も表現の平易さも変わるためだ。
3. 教員として、学年を毎回入力せずに済ませたい。それはクラスを選んだ時点で学年が決まっており、入力は手間と打ち間違いのもとだからだ。

## 機能要件

### ひな形の初期値の差し替え(F10)

- Given: プロンプトひな形を一度も保存していない教員である
  When: 所見管理画面でAI生成セクションを開く、またはプロンプトひな形編集画面を開く
  Then: 学習の所見用・生活の所見用のいずれも、新しい文面が初期値として表示される

- Given: 既にプロンプトひな形を自分で編集・保存している教員である
  When: プロンプトひな形編集画面を開く
  Then: 自分が保存した内容がそのまま表示される(初期値の差し替えによって上書きされない)

### 学年の自動反映(F9, F10)

- Given: 所見管理画面でクラスを選択している
  When: 生徒の行のAI生成セクションを開く
  Then: 「学年」の入力欄に、選択中のクラスの学年(通常学年は「1」〜「6」、特別支援学級は「特支」)が既定値として入っている

- Given: AI生成セクションの「学年」欄に値が入っている
  When: プロンプトを表示する、またはAIで直接生成する
  Then: ひな形の`{{grade}}`がその値に置き換わる

- Given: AI生成セクションの「学年」欄を教員が書き換える
  When: プロンプトを表示する、またはAIで直接生成する
  Then: 書き換えた値が`{{grade}}`に反映される。クラスの学年データそのものは変更されない

- Given: 「学年」欄を空にする
  When: プロンプトを表示する
  Then: `{{grade}}`が「指定なし」に置き換わる(目安文字数と同じ扱い)

- Given: クラスを切り替える
  When: 別のクラスの生徒の行でAI生成セクションを開く
  Then: 「学年」欄には切り替え後のクラスの学年が入っている(前のクラスの値が残らない)

### プレースホルダーの案内(F10)

- Given: プロンプトひな形編集画面を開いている
  When: ひな形編集欄の案内文を読む
  Then: 使用できるプレースホルダーとして`{{grade}}`(学年)が、既存の`{{targetCharCount}}`(目安文字数)・`{{memos}}`(メモ一覧)と並んで案内されている

## 非機能要件

- `buildPrompt`は、ひな形に含まれていないプレースホルダーがあっても、含まれているプレースホルダーだけを置換して正常に動作する(教員が自分のひな形から特定のプレースホルダーを消していてもエラーにしない)
- 学年の入力欄は`docs/design/design-system.md`の既存トークン・既存の`Input`コンポーネントで実装する

## スコープ外

- **学期のプレースホルダー**: 教員から提示された文面には「学期」の項目があったが、本ツールは学期という概念を持たず(対象期間を開始日・終了日で指定する設計)、`class_comment_period`にも学期に相当する情報がない。文面から学期の行を削除して採用する
- **仮名コードのプレースホルダー**: 新しい文面は仮名コードを含まない。メモは1生徒分のみを渡すため機能上の不足はなく、生成結果に仮名コード(「1-03-10」等)が混入するリスクも下がる。従来の初期値にあった`{{pseudonymCode}}`は初期値から外す(教員が自分のひな形で使い続けることは可能で、`buildPrompt`は引き続き置換する)
- **総合の所見用のひな形**: 総合の所見自体が未実装のため、本改修では扱わない。教員から提示された総合用の文面は`docs/features/general-shoken/`(次のPR)で初期値として採用する
- **保存済みひな形の一括上書き**: 教員が自分で編集した内容を消さない方針のため行わない
- **学年を`class`テーブル以外から取る仕組み**・学年ごとのひな形の出し分け

## 用語

| 用語 | 定義 |
|---|---|
| ひな形(プロンプトテンプレート) | `{{grade}}`・`{{targetCharCount}}`・`{{memos}}`等のプレースホルダーを含む、AIへ送るプロンプトの雛形。教員ごとに`prompt_template`テーブルで保持し、未保存なら本ツール既定の初期値を使う |
| 初期値 | `shared/prompt-builder.ts`がコードとして持つ既定のひな形。教員が保存していない場合にのみ使われる |
| 学年 | プロンプトに埋め込む学年。既定値は対象クラスの`class.grade`(「1」〜「6」または「特支」)で、AI生成セクションで上書きできる |
