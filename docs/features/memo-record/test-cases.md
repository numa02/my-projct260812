## TC-001: 科目またはクラスが未設定の日時では記録できない案内が表示される(空状態)

- 優先度: P0
- 種別: UI
- 観点: 空状態
- 自動テスト: `e2e/memos-record.spec.ts`

### 前提条件
- 時間割マスタが一部のマスにのみ設定されている

### 操作手順
1. 未設定のマスに対応する日付・時限を指定して `/memos/record` を開く

### 期待結果
- 「この時間には科目またはクラスが設定されていないため、記録できません」が表示される
- 生徒一覧・メモ入力欄は表示されない

### 確認した環境
- [ ] Chrome (Mac)

## TC-002: 生徒名をクリックして展開し、メモを個別に保存できる。他の生徒の行には影響しない

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/memos-record.spec.ts`

### 前提条件
- 科目・クラスが設定された日時で、生徒が2人以上登録されたクラス

### 操作手順
1. 生徒Aの行をクリックして展開する
2. メモを入力して保存する
3. 生徒Aの行を折りたたむ
4. 生徒Bの行をクリックして展開する

### 期待結果
- 生徒Aの保存後、折りたたんだ状態でも「入力済み」インジケーターが表示される
- 生徒Bの行は生徒Aの操作の影響を受けず、未入力のまま(メモ欄が空)

### 確認した環境
- [ ] Chrome (Mac)

---

## TC-003: 共有区分を「共有しない」に変更して保存できる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/memos-record.spec.ts`

### 前提条件
- 生徒の行を展開している(共有区分は初期値「共有する」)

### 操作手順
1. 共有区分トグルを「共有しない」に切り替える
2. メモを入力して保存する
3. 行を折りたたんでから再度展開する

### 期待結果
- 「共有しない」の状態では「本文に書いた氏名等の情報はそのままAIへ送信されます」の注意文が表示されない
- 保存後、再展開すると内容・共有区分が保存した状態のまま復元される

### 確認した環境
- [ ] Chrome (Mac)
