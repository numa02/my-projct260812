## TC-001: 所感が1件もない場合は案内が表示され、手動作成・生成タブへの導線がある(空状態)

- 優先度: P0
- 種別: UI
- 観点: 空状態
- 自動テスト: `e2e/comments-history.spec.ts`

### 前提条件
- 対象生徒に所感が1件も保存されていない

### 操作手順
1. 履歴タブを開く

### 期待結果

- 「手動で作成する」ボタン、「生成」タブへのリンクが表示される
- リンクをクリックすると「生成」タブに切り替わる

### 確認した環境
- [ ] Chrome (Mac)

## TC-003: 一覧から選択した所感を編集して保存すると内容が更新される

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/comments-history.spec.ts`

### 前提条件
- 所感が1件保存されている

### 操作手順
1. 一覧からその所感を選択する(期間は読み取り専用になることを確認)
2. 本文を編集して保存する

### 期待結果
- 編集後の内容でその生徒・その期間の所感が更新され、編集前の内容は残らない
- 同じ生徒の他の期間の所感には影響しない

### 確認した環境
- [ ] Chrome (Mac)
