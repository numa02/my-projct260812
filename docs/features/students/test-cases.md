## TC-002: クラスを切り替えると生徒一覧・インポート対象が切り替わる

- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/students.spec.ts`

### 前提条件
- クラスが2件登録済み(生徒0人)

### 操作手順
1. クラスAを選択し、テキスト貼り付けで生徒を1人登録する

## TC-004: 仮名コードが表示され、生徒削除には確認ダイアログが必要

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/students.spec.ts`

### 前提条件
- 出席番号10番の生徒が学年1・組番号1のクラスに登録済み

### 操作手順

- 削除実行後、一覧から消える

## TC-005: クラスが複数登録済みの状態で画面を開くと、先頭のクラスが自動選択され生徒一覧が表示される(`docs/bugs.md` BUG-002再発防止)

- 優先度: P0
- 種別: UI
- 観点: 正常系
- 自動テスト: 未対応(手動確認。クラス選択の`<select>`は元々「値が未選択でも見た目上は先頭が選択済みに見える」ため自動テストでは検知しづらく、目視確認が重要)

### 前提条件
- クラスが2件以上、うち少なくとも1件に生徒が登録済み

### 操作手順
1. 他の画面からではなく直接 `/students` にアクセスする(明示的にクラスを選んでいない状態を作る)

### 期待結果
- クラス選択が何もしなくても先頭のクラスが選択された状態になっており、そのクラスの生徒一覧・インポート欄がすぐに表示される
- 「クラス選択の見た目は先頭が選択されているのに、一覧やインポート欄が空のまま」という状態にならない(BUG-002: 状態と表示のズレにより生徒一覧が空に見えるバグの再発防止)

### 確認した環境
- [ ] Chrome (Mac)
