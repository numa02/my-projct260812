# 要件定義: 生活所見の記録

`docs/requirements.md` F6(授業記録)・F7(生徒別メモ一覧)・F9〜F11(所見の生成・保存)・F14(エクスポート)を拡張する追加機能。授業に紐づかない生徒の様子(休み時間・給食・清掃・行事など)を「生活メモ」として記録し、所見を「学習の所見」と「生活の所見」の2種類に分けて保存・AI生成できるようにする。

## 機能概要

1. 週次時間割に曜日ごとの「生活記録」マスを追加し、そこからその日付の生活記録画面を開いて、クラスの生徒ごとに生活メモを記録できる
2. 生徒別メモ一覧から、日付を入力(選択)して生活メモを1件追加できる。一覧には授業メモと生活メモが並んで表示され、生活メモも編集・削除・共有区分の切替ができる
3. 所見管理画面を「学習の所見」「生活の所見」のタブで切り替えられるようにし、それぞれ別々に保存・AI生成できる。学習の所見の材料は授業メモ、生活の所見の材料は生活メモ
4. プロンプトひな形を「学習の所見用」「生活の所見用」の2種類持ち、それぞれ編集できる

## ユーザーストーリー

1. 教員として、授業以外の場面で気づいた生徒の様子を、その日のうちに短く記録したい。それは通知表の「行動・生活の所見」を書くときの材料にするためだ。
2. 教員として、あとから思い出した出来事を、日付を指定して生徒ごとに追記したい。それは記録漏れを後から補うためだ。
3. 教員として、学習面の所見と生活面の所見を別々に作成したい。それは通知表の欄が分かれているためだ。

## 機能要件

### 生活メモの記録(週次時間割から)

- Given: 週次時間割画面を開いている
  When: 表示中の週のある曜日の「生活記録」マスを押す
  Then: その日付を指定した状態で生活記録画面が開く。「戻る」で週次時間割画面に戻れる

- Given: 生活記録画面で、その日の時間割(個別変更を反映した後)に登場するクラスが1つだけ
  When: 画面が表示される
  Then: そのクラスが対象として自動で決まり、クラス選択欄は表示されない。そのクラスの生徒一覧が表示される

- Given: 生活記録画面で、その日の時間割に登場するクラスが2つ以上(教科担任制)、または1つもない(時間割未設定・土日など)
  When: 画面が表示される
  Then: クラス選択欄が表示される。候補は、2つ以上の場合はその日に登場するクラス、1つもない場合は登録済みの全クラス。既定値は候補の先頭

- Given: 生活記録画面で生徒の行を開く
  When: メモと共有区分を入力して保存する
  Then: その生徒・その日付の生活メモとして保存される(1人1日1件。既にある場合は上書き)。行に「入力済み」が表示される

- Given: 生活記録画面の日付欄
  When: 日付を変更する
  Then: その日付の生活メモ・クラス判定に切り替わる

### 生活メモの追加(生徒別メモ一覧から)

- Given: 生徒別メモ一覧で生徒を選択している
  When: 「生活メモを追加」を押し、日付(初期値は今日)・メモ・共有区分を入力して保存する
  Then: 生活メモが保存され、一覧に「生活記録」として表示される

- Given: 同じ生徒・同じ日付の生活メモが既にある
  When: その日付で追加しようとする
  Then: 「この日付の生活メモは既にあります。一覧から編集してください」と表示され、保存されない(入力内容は保持する)

- Given: 生徒別メモ一覧で生徒を選択している
  When: 一覧を表示する
  Then: 授業メモと生活メモが日付の新しい順に並ぶ。生活メモは科目・時限の代わりに「生活記録」と表示される。「教科別」表示では「生活記録」が1つのグループになる(小学校の教科「生活」の授業メモとは別グループ。`docs/features/ui-clarity/`)。生活メモも編集・削除・共有区分の切替ができる

### 所見(学習・生活)

- Given: 所見管理画面で対象期間を指定している
  When: 「学習の所見」タブを選ぶ
  Then: 従来どおりの所見(以後「学習の所見」)の入力・保存・AI生成ができる。AI生成の材料は対象期間内の「共有する」区分の授業メモ

- Given: 所見管理画面で対象期間を指定している
  When: 「生活の所見」タブを選ぶ
  Then: 生徒ごとに生活の所見の入力・保存・AI生成ができる。AI生成の材料は対象期間内の「共有する」区分の生活メモ。生活の所見は学習の所見とは独立に、生徒につき1件保持する

- Given: プロンプトひな形編集画面
  When: 画面を開く
  Then: 「学習の所見用」「生活の所見用」の2つのひな形が表示され、それぞれ保存できる。未保存のひな形は本ツールの既定値が表示される

### エクスポート

- Given: データエクスポートを実行する
  When: JSONを出力する
  Then: 生徒ごとに生活メモ(`lifeMemos`)・生活の所見(`lifeComments`)が含まれ、プロンプトひな形には生活の所見用(`lifeContent`)も含まれる

## 非機能要件

- 生活メモ・生活の所見はRLSで自分の生徒のものだけを扱える(授業メモ・所見と同じ)
- 「共有する」区分の生活メモのみがAIに送られる(授業メモと同じ)

## スコープ外

- 生活メモの場面タグ(休み時間・給食など)
- 1人1日に複数件の生活メモ
- 生活記録画面へのサイドナビからの直接の導線(授業記録画面と同じく、週次時間割・生徒別メモ一覧から開く)
- 学習の所見の材料に生活メモを含める、またはその逆

## 用語

| 用語 | 説明 |
|---|---|
| 授業メモ | 従来の「メモ」。授業(日付・時限・科目)に紐づく生徒ごとの記録 |
| 生活メモ | 授業に紐づかない、日付ごとの生徒の様子の記録。1人1日1件 |
| 学習の所見 | 従来の「所見」。授業メモを材料にする |
| 生活の所見 | 生活メモを材料にする所見。学習の所見とは別に生徒ごとに1件 |
