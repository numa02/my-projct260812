# 影響範囲: 生活所見の記録

## 既存機能への影響

| 機能 | 影響 |
|---|---|
| 週次時間割 | グリッドに「生活」行が追加される。既存のマス・個別変更・授業記録への導線は変更なし |
| 時間割マスタ設定 | 影響なし(生活行は表示しない) |
| 授業記録 | 影響なし |
| 生徒別メモ一覧 | 生活メモが一覧に並ぶ。「生活メモを追加」が増える。既存の授業メモの編集・削除・共有区分切替は変更なし |
| 所見管理 | 「学習の所見」「生活の所見」のタブが増える。既存の所見は「学習の所見」タブにそのまま表示される |
| プロンプトひな形編集 | 生活の所見用のひな形が増える。既存のひな形は「学習の所見用」としてそのまま使われる |
| データエクスポート | `lifeMemos`・`lifeComments`・`promptTemplate.lifeContent`が追加される。既存キーは変わらない |
| 生徒・クラスの削除 | 生活メモ・生活の所見も`on delete cascade`で削除される(確認ダイアログの「メモ・所見もすべて削除」の説明に含まれる) |

## データへの影響

既存データの変更・移行はない。既存の所見はすべて「学習の所見」として扱われる。

## テストへの影響

`design.md`「影響を受ける既存テスト」を参照。

## ドキュメントへの影響

- `docs/requirements.md`: F5〜F7・F9〜F11・F14、用語集
- `docs/data-model.md`・`docs/design.md` §4・§5: 新テーブル・`prompt_template`の変更・エクスポート
- `docs/design/screens.md`・`docs/design/user-flow.md`: 生活記録画面の追加、週次時間割・生徒別メモ一覧・所見管理・プロンプトひな形編集の変更
- `mockups/`: `weekly-timetable.html`・`student-memo-list.html`・`comment.html`・`settings.html`の更新、`life-record.html`の新規
