# テストケース: 生活所見の記録

## 最低限のテスト(P0)

### LS-P0-01 週次時間割の「生活記録」マスから生活メモを記録できる(担任クラス)

- 自動テスト: `e2e/life-shoken.spec.ts`
- 前提: 一括モードで時間割マスタを設定済み(クラス1つ)、生徒が1人以上
- 手順: 週次時間割で任意の曜日の「生活記録」を押す → 生徒の行を開いてメモを入力し保存 → 「戻る」
- 期待結果: 押した曜日の日付で生活記録画面が開く。クラス選択欄は出ずクラス名が表示される。保存後「入力済み」が付く。「戻る」で週次時間割に戻る
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P0-02 教科担任制ではクラスを選べる

- 自動テスト: `e2e/life-shoken.spec.ts`
- 前提: 教科担任制モードで、同じ曜日に2つのクラスの授業を設定済み
- 手順: その曜日の生活記録画面を開き、クラスを切り替える
- 期待結果: クラス選択欄にその日のクラスだけが並び、選んだクラスの生徒が表示される
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P0-03 生徒別メモ一覧から日付を選んで生活メモを追加できる

- 自動テスト: `e2e/life-shoken.spec.ts`
- 手順: 生徒を選び「生活メモを追加」→ 日付・メモを入力して保存 → 同じ日付でもう一度追加
- 期待結果: 1回目は一覧に「日付 ・ 生活記録」として表示される(教科別では「生活記録」グループ。教科「生活」の授業メモとは別グループ)。2回目は「この日付の生活メモは既にあります」と表示され、入力内容は残る
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P0-04 生活の所見は生活メモだけを材料にし、学習の所見とは別に保存される

- 自動テスト: `e2e/life-shoken.spec.ts`
- 前提: 同じ期間に授業メモと生活メモが1件ずつある
- 手順: 所見管理で「生活の所見」タブ → AIで生成する(プロンプトを作成) → 手入力して保存 → 「学習の所見」タブに切り替え
- 期待結果: プロンプトに生活メモだけが含まれる。学習の所見タブの入力欄は空のまま。再読み込み後も生活の所見が復元される
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P0-05 生活の所見用のひな形を別に編集できる

- 自動テスト: `e2e/life-shoken.spec.ts`
- 手順: プロンプトひな形編集で生活の所見用だけを編集・保存 → 所見管理の生活の所見タブでプロンプトを表示
- 期待結果: 生活の所見のプロンプトに反映され、学習の所見用のひな形は既定値のまま
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

## 後で確認するテスト(P1)

- 期待結果: 全クラスから選べるクラス選択欄が表示される
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P1-02 生活メモの編集・削除・共有区分切替

- 手順: 生徒別メモ一覧で生活メモを編集・共有区分切替・削除する
- 期待結果: 授業メモと同じように反映され、授業メモには影響しない
- [x] Chrome (Mac)(本番で確認: 2026-09-20)

### LS-P1-04 既存データへの影響がない(本番運用中の追加機能)

- 前提: 本機能リリース前に所見・ひな形を保存済みのアカウント
- 期待結果: 既存の所見は「学習の所見」タブにそのまま表示され、既存のひな形は「学習の所見用のひな形」として表示される
- [x] Chrome (Mac)(本番で確認: 2026-09-20。既存のひな形が「学習の所見用のひな形」として表示されることを確認)
