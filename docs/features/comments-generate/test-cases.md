## 最低限のテスト(P0)

## TC-001: 期間・目安文字数を指定して生成すると、AIの応答テキストがそのまま表示され保存できる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/comments-generate.spec.ts`

### 前提条件
- APIキー設定済み。対象生徒に「共有する」メモが1件以上ある期間を指定できる

### 操作手順
1. 開始日・終了日・目安文字数を指定する
2. 「生成」を実行する
3. 生成結果を確認し「保存」を実行する

### 期待結果
- プロンプトに仮名コードが含まれる(氏名は含まれない)
- AIの応答テキストがそのまま生成結果欄に表示される(仮名コードの検出・実名置換は行わない)
- 保存が成功し「所感を保存しました」が表示される

### 確認した環境
- [ ] Chrome (Mac)

## TC-002: 同じ期間で再度保存しようとすると上書き確認ダイアログが表示される

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/comments-generate.spec.ts`

### 前提条件
- 同じ生徒・同じ期間の所感が既に保存されている

### 操作手順
1. 同じ期間で再度生成(または生成結果を編集)し、保存を実行する

### 期待結果
- 「この期間の所感は既に保存されています。上書きしますか」の確認ダイアログが表示される
- 続行すると新しい内容で上書きされる。キャンセルすると既存の内容は変更されない

### 確認した環境
- [ ] Chrome (Mac)
