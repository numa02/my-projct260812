## 最低限のテスト(P0)

## TC-001: 期間・目安文字数を指定して生成すると、AIの応答テキストがそのまま表示され保存できる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/comments-generate.spec.ts`

### 前提条件
- APIキー設定済み。対象生徒に「共有する」メモが1件以上ある期間を指定できる

### 操作手順
1. 開始日・終了日・目安文字数を指定する
2. 「生成」を実行する
3. 生成結果を確認し「保存」を実行する

### 期待結果
- プロンプトに仮名コードが含まれる(氏名は含まれない)
- AIの応答テキストがそのまま生成結果欄に表示される(仮名コードの検出・実名置換は行わない)
- 保存が成功し「所感を保存しました」が表示される

### 確認した環境
- [ ] Chrome (Mac)

## TC-006: APIキー未設定の場合、プロンプトが表示されコピーでき、貼り付けたテキストをそのまま保存できる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/comments-generate.spec.ts`(クリップボード権限を付与して実際のコピー内容も検証)

### 前提条件
- AIプロバイダのAPIキーが未設定。対象生徒に「共有する」メモが1件以上ある期間を指定できる

### 操作手順
1. 開始日・終了日を指定する
2. 表示されたプロンプトを確認し、「プロンプトをコピー」を実行する
3. 外部AIサービスから得た応答を貼り付け欄に入力し、「保存」を実行する

### 期待結果
- プロンプトに仮名コードは含まれるが生徒の実名は含まれない
- コピーしたクリップボードの内容がプロンプトと一致する
- 貼り付けたテキストがそのまま(仮名コードの検出・実名置換なしで)所感として保存される

### 確認した環境
- [ ] Chrome (Mac)
