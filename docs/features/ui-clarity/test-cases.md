# テストケース: 画面表示の分かりにくさの解消

対応する要件は`docs/features/ui-clarity/requirements.md`。個別画面の既存ケースは各画面のテストケース表(`docs/features/classes/test-cases.md` TC-002・TC-104、`docs/features/settings-ai-provider/test-cases.md` TC-001・TC-002、`docs/features/life-shoken/test-cases.md` LS-P0-01・LS-P0-03)側で更新済みで、ここでは本改修に固有の横断ケースのみを扱う。

## 最低限のテスト(P0)

### UC-P0-01 クラス管理画面に組番号が表示されない

- 優先度: P0
- 自動テスト: `e2e/classes.spec.ts`
- 前提: クラスが2件以上登録済み
- 手順: `/classes`をデスクトップ幅で開く → ウィンドウをタブレット幅(768px〜1279px)に狭めてカード表示にする
- 期待結果: 表形式では「学年」「クラス表示名」と操作列のみが並び「組番号」列がない。カード表示でもメタ表記が学年だけになり「組番号」の文字が出ない。クラスの作成・編集・削除は従来どおり動作する

### UC-P0-02 組番号は仮名コードとして従来どおり機能している

- 優先度: P0
- 自動テスト: `tests/db/rpc-class.test.ts`(採番)。画面確認は手動
- 前提: 同学年に2クラス、それぞれに生徒を1人登録済み
- 手順: 生徒名簿画面で2クラス分の仮名コードを確認する
- 期待結果: 仮名コードが「1-01-01」「1-02-01」のように組番号を含む形で表示され、クラスごとに異なる。組番号を画面から隠しても採番・仮名コード生成に影響していない

### UC-P0-03 APIキーの設定状況が一目で分かる

- 優先度: P0
- 自動テスト: `e2e/settings-ai-provider.spec.ts`
- 前提: AIプロバイダ未設定のアカウントでログイン
- 手順: `/settings/ai-provider`を開く → APIキーを入力して保存する
- 期待結果: 保存前は「APIキー」ラベルの横に控えめな「未設定」バッジ。保存後は画面の再読み込みなしで緑のドット付き「設定済み」バッジに変わり、その横に登録済みのプロバイダ名・モデル名が併記される。「未設定」と「設定済み」が色と形で明確に見分けられる

### UC-P0-04 教科「生活」の授業メモと生活メモが区別される

- 優先度: P0
- 自動テスト: `e2e/life-shoken.spec.ts`
- 前提: 小学校の標準科目セットを投入して教科「生活」が登録済み。同じ生徒に教科「生活」の授業メモ1件と生活メモ1件がある
- 手順: 生徒別メモ一覧でその生徒を選び、「日付順」→「教科別」の順に表示を切り替える
- 期待結果: 日付順では授業メモが「日付 ・ 時限 ・ 生活」、生活メモが「日付 ・ 生活記録」と表示され区別できる。教科別では「生活」と「生活記録」が別グループに分かれ、1つのグループに混ざらない

### UC-P0-05 週次時間割の行見出しが「生活記録」になっている

- 優先度: P0
- 自動テスト: `components/timetable/TimetableGrid.test.tsx`
- 前提: ログイン済み
- 手順: `/timetable/weekly`を開き、6限の下の行を確認する
- 期待結果: 行見出しが「生活記録」と表示され、各曜日のマスのボタン文言(「生活記録」)と表記が揃っている。マスを押すとその日付の生活記録画面が開く(挙動は従来どおり)

## 後で確認するテスト(P1〜P3)

### UC-P1-01 長いモデル名でも設定状況の行が崩れない

- 優先度: P1
- 自動テスト: 未対応(手動確認)
- 手順: 最も名前の長いモデルを選んで保存し、タブレット幅で設定画面を表示する
- 期待結果: 「APIキー」ラベル・バッジ・プロバイダ名/モデル名が1行に収まらない場合も折り返しで表示され、入力欄やボタンに重ならない

### UC-P2-01 プロバイダを選び直しただけでは併記内容が変わらない

- 優先度: P2
- 自動テスト: 未対応(手動確認)
- 前提: OpenAIで保存済み
- 手順: プルダウンでAnthropicに切り替えるが、保存はしない
- 期待結果: バッジは「設定済み」のまま、併記されるのは保存済みの「OpenAI / (モデル名)」のまま変わらない(未保存の選択が登録済み内容として表示されない)
