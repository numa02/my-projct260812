# 要件: 画面表示の分かりにくさの解消

## 機能概要

教員から寄せられた「画面を見ても仕様が推測できない・状態が分からない」という3点を解消する。いずれもデータモデルの変更を伴わない表示の変更で、既存の振る舞い(採番規則・保存処理・生成処理)そのものは変えない。

1. クラス管理画面の「組番号」列を表示しない
2. AIプロバイダ設定画面で、APIキーが登録済みであることが一目で分かるようにする
3. 生活メモの表示ラベルを「生活」から「生活記録」に変える(小学校の教科「生活」との区別)

3については、同じPRで小学校の標準科目セットに教科「生活」を追加する(`docs/features/subjects/` SJ-011〜)。教科「生活」が登録できるようになると生活メモのラベル「生活」と衝突するため、両者は必ず同時に反映する。

## ユーザーストーリー

1. 教員として、クラス管理画面に意味の分からない番号が出ていない状態でクラスを管理したい。それは組番号が仮名コード生成のための内部的な連番であり、教員が採番規則(学年区分ごとの作成順・欠番は再利用しない)を知る必要がないためだ。
2. 教員として、APIキーを登録したかどうかを設定画面で一目で確認したい。それは登録済みでも画面の見た目がほとんど変わらず、登録できたのか分からないままもう一度入力してしまうためだ。
3. 教員として、小学校の教科「生活」の授業メモと、授業に紐づかない生活メモを一覧で区別したい。それは生徒別メモ一覧の「教科別」表示で両者が同じグループにまとめられてしまうためだ。

## 機能要件

### 組番号の非表示(F1)

- Given: クラスが1件以上登録されている
  When: クラス管理画面を開く
  Then: 一覧には学年とクラス表示名のみが表示され、組番号は表示されない。デスクトップの表形式・タブレットのカード形式のいずれでも表示しない

- Given: クラスを新規作成する、または既存クラスの学年を変更する
  When: 保存する
  Then: 組番号の自動採番・再採番は従来どおり行われる(F1の採番規則は変更しない)。採番された番号は画面に表示しないが、仮名コード(例: 「1-03-10」)の一部として生徒名簿・所見管理画面で従来どおり見える

### APIキーの設定状況表示(F9)

- Given: APIキーを登録していない
  When: AIプロバイダ設定画面を開く
  Then: 「APIキー」の見出しに続けて「未設定」のバッジが表示される

- Given: APIキーを登録済みである
  When: AIプロバイダ設定画面を開く
  Then: 「APIキー」の見出しに続けて「設定済み」のバッジが、授業記録画面の「入力済み」インジケーターと同じドット付きの強調表示で表示される。あわせて登録済みのプロバイダ名とモデル名が併記される

- Given: AIプロバイダ設定画面でAPIキーを保存する
  When: 保存が成功する
  Then: 同じ画面のまま表示が「未設定」から「設定済み」に変わり、併記されるプロバイダ名・モデル名も保存した内容に更新される(画面の再読み込みを必要としない)

### 生活メモの表示ラベル(F7)

- Given: 生徒に授業メモと生活メモの両方がある
  When: 生徒別メモ一覧を「日付順」で表示する
  Then: 生活メモは時限・科目の代わりに「生活記録」と表示される

- Given: 生徒に教科「生活」の授業メモと生活メモの両方がある
  When: 生徒別メモ一覧を「教科別」で表示する
  Then: 教科「生活」のグループと「生活記録」のグループが別のグループとして表示される

- Given: 週次時間割画面を開いている
  When: グリッドを見る
  Then: 6限の下の行見出しが「生活記録」と表示される(各曜日のマスのボタン文言は従来どおり「生活記録」)

## 非機能要件

- 追加・変更する色・フォントサイズ・余白は`docs/design/design-system.md`にあるトークンのみを使う。新しいトークンは追加しない
- 既存のBadgeコンポーネントにバリエーションを追加しない(「入力済み」で使っている`recorded`を再利用する)

## スコープ外

- 組番号そのものの廃止・採番規則の変更(仮名コード生成が依存しているため維持する)
- 仮名コードの表記から組番号を除くこと(過去にAIへ送信済みの仮名コードとの整合性が崩れるため行わない)
- APIキーの有効性検証(登録済みのキーが実際に使えるかをAIプロバイダに問い合わせる機能)。「設定済み」は保存されているかどうかのみを表す
- 生活記録画面・生活メモそのものの仕様変更(ラベル表記のみを変える)

## 用語

| 用語 | 定義 |
|---|---|
| 組番号 | クラスごとに自動付与される内部管理用・仮名コード生成用の連番。本改修以降、画面には表示しない |
| 生活記録 | 授業に紐づかない生徒の様子の記録(生活メモ)の表示上の呼称。小学校の教科「生活」と区別するために用いる |
| 設定済み | AIプロバイダ設定でAPIキーが保存されている状態。キーが有効であることは意味しない |
