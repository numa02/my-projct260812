# テストケース一覧: 所感管理(クラス単位一覧)

最終更新: 2026-08-18
対象タスク: T-080(T-065〜T-067を再設計・置換) / 対応要件: F9, F10, F11, F12
対象画面: `/comments/class/[[...id]]`(`id`は任意。生徒名簿画面からの遷移時のみ初期選択クラスのヒントとして付与される)

クラスと対象期間(開始日・終了日、画面全体で1つ)を指定すると、そのクラス全員分の所感入力欄が一覧表示される。氏名と所感入力欄は常時表示、AI生成(F9, F10)・過去の所感の閲覧(F11)は生徒の行ごとに折りたたみで開く。AIで直接生成するかプロンプトを作成するかはAPIキー設定状況から既定値が決まるが、教員はいつでも切り替えられる。

## 凡例
- 優先度: P0(必須) / P1(高) / P2(中) / P3(低)
- 種別: 機能 / UI / 性能 / セキュリティ
- 自動テスト: `e2e/comments-class.spec.ts` でカバーしているものは明記

## TC-006: APIキー設定済みの場合、AI生成した内容が所感欄に反映され保存できる(F9)

### 確認した環境
- [ ] Chrome (Mac)
