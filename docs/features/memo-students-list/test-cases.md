## TC-001: 生徒名簿画面から生徒名をクリックするとクラス・生徒が選択済みで表示され、「戻る」で戻れる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/memos-students.spec.ts`

### 前提条件
- 生徒が1人登録済み(メモは0件)

### 操作手順
1. `/students` でその生徒の氏名リンクをクリックする
2. 「戻る」を押す

### 期待結果
- クラス選択・生徒選択が自動的にその生徒に設定された状態で表示される
- メモが0件のため「まだメモがありません」が表示される
- 「戻る」で `/students` に戻る

### 確認した環境
- [ ] Chrome (Mac)

## TC-002: メモが日付順・教科別で一覧表示され、編集・削除・共有区分切替ができる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/memos-students.spec.ts`

### 前提条件
- 同じ生徒に、異なる科目(国語・算数)のメモが1件ずつ登録済み

### 操作手順
1. 日付順表示で両方のメモが表示されることを確認する
2. 「教科別」に切り替え、科目ごとの見出しでグループ化されることを確認する
3. いずれかのメモを編集して保存する
4. いずれかのメモの共有区分を切り替える
5. いずれかのメモを削除する

### 期待結果
- 日付順は新しい順、教科別は科目ごとにグループ化され各グループ内は新しい順に表示される
- 編集・共有区分切替・削除がそれぞれ即座に反映され、トーストが表示される
- 共有区分の切替時は「過去にAIへ送信済みの内容そのものは取り消せません」の注意が表示される
- 削除したメモは一覧から消える

### 確認した環境
- [ ] Chrome (Mac)

## TC-003: ナビゲーションメニューから直接開くと、クラスは既定選択・生徒は未選択の状態で表示され、生徒を選ぶとメモが見られる

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/memos-students.spec.ts`

### 前提条件
- クラスが1件以上、そのクラスに生徒が1人以上登録済み

### 操作手順
1. `/students` など他の画面から、サイドバーの「生徒別メモ一覧」をクリックする
2. 生徒を選択する

### 期待結果
- `/memos/students` に遷移し、「戻る」ボタンは表示されない(戻り先が定まらないため)
- クラス選択は明示的な操作なしに先頭のクラスが選択された状態で表示される
- 生徒選択は未選択の状態(「選択してください」)で始まり、「生徒を選択してください」の案内が表示される
- 生徒を選択すると、その生徒のメモ一覧(または「まだメモがありません」)が表示される

### 確認した環境
- [ ] Chrome (Mac)

## TC-102: 画面内のクラス選択を切り替えると生徒選択の候補が絞り込まれる

- 優先度: P1
- 種別: 機能
- 観点: 正常系
- 自動テスト: 未対応(手動確認)

### 前提条件
- クラスが2件あり、それぞれに生徒が登録済み

### 操作手順
1. クラスAを選択して生徒選択の候補を確認する
2. クラスBに切り替えて生徒選択の候補を確認する

### 期待結果
- 生徒選択の候補が選択中クラスの生徒のみに絞り込まれる
- この絞り込みは他の画面(生徒名簿等)のクラス選択状態に影響しない
- クラス切替直後、生徒選択は未選択に戻り「生徒を選択してください」が表示される。生徒選択の`<select>`自体も「選択してください」のプレースホルダーが見た目上選択された状態になっており、切替先クラスの先頭の生徒が誤って選択済みのように見えない(`docs/bugs.md` BUG-003再発防止)

### 確認した環境
- [ ] Chrome (Mac)
