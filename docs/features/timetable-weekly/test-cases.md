## TC-001: 時間割マスタ未設定(サインアップ直後)でも今週の週次時間割を表示できる(空状態)

- 優先度: P0
- 種別: UI
- 観点: 空状態
- 自動テスト: `e2e/timetable-weekly.spec.ts`

### 前提条件
- サインアップ直後で、時間割マスタを一度も保存していないアカウントでログイン

### 操作手順
1. `/timetable/weekly` を開く

### 期待結果
- 今週(今日を含む月曜始まりの週)の日付範囲「yyyy年M月d日(月)〜M月d日(金)」が表示される
- 全マスが未設定のグリッドが表示される(時間割マスタ設定画面への誘導は表示されない)
- 「第◯週」の表示がない

### 確認した環境
- [ ] Chrome (Mac)

## TC-002: 日付範囲の表示、マスタ内容の表示、週送り・週指定ナビゲーション

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/timetable-weekly.spec.ts`

### 前提条件
- 時間割マスタが設定済み

### 操作手順
1. 「週を指定」で任意の週(例: 2026-04-06)を表示する
2. 「次の週へ」「前の週へ」で週を送る
3. 「週を指定」で任意の日付の週にジャンプする

### 期待結果
- 日付範囲(月曜〜金曜)が正しく表示され、「第◯週」は表示されない
- グリッドにマスタ内容(科目・クラス)が表示される
- 週送り・週指定のいずれでも正しい週に切り替わる

### 確認した環境
- [ ] Chrome (Mac)

## TC-003: マスの個別変更を保存すると「変更あり」表示になり、他の週には影響しない

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/timetable-weekly.spec.ts`

### 前提条件
- 時間割マスタが設定済み

### 操作手順
1. マスをクリックしてマス編集モーダルを開く
2. 科目・クラスをマスタと異なる内容に変更して保存する
3. 翌週の同じマスを確認する

### 期待結果
- 保存したマスに「変更あり」バッジが表示される
- 翌週の同じマス(曜日・時限)はマスタ通りのまま(個別変更の影響を受けない)

### 確認した環境
- [ ] Chrome (Mac)
