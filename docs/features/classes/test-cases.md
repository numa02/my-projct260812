## TC-002: 通常学年・特支いずれでもクラスが作成され、一覧に組番号が表示されない(正常系)

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/classes.spec.ts`

### 前提条件
- ログイン済み、クラス0件

### 操作手順
1. 学年「1」・表示名「1年1組」でクラスを作成
2. 学年「1」・表示名「1年2組」でクラスを作成
3. 「特別支援学級(特支)」をONにして表示名「ひまわり組」でクラスを作成

### 期待結果
- 一覧に3件とも表示され、各行に学年とクラス表示名のみが並ぶ
- 「組番号」の列・表記が画面のどこにも出ない(仮名コード生成用の内部的な連番のため。採番規則そのものの検証は`tests/db/rpc-class.test.ts`が担う)
- ひまわり組は学年が「特支」として表示される

### 確認した環境
- [ ] Chrome (Mac)

## TC-104: 同学年で3クラス目以降を作っても組番号が正しく連番になる(境界値)

- 優先度: P2
- 種別: 機能
- 観点: 境界値
- 自動テスト: `tests/db/rpc-class.test.ts`(採番ロジック)。画面からの確認は手動

### 前提条件
- 同学年のクラスが2件登録済み

### 操作手順
1. 同学年のクラスをさらに1件作成する
2. 1件を削除してから、もう1件作成する(欠番の埋まり方を確認)
3. それぞれのクラスに生徒を1人登録し、生徒名簿画面で仮名コードを確認する

### 期待結果
- 組番号の採番ロジックが仕様(`docs/design.md`)通りであることを確認する
- クラス管理画面には組番号が表示されないため、確認は生徒名簿画面の仮名コード(「学年-組番号-出席番号」形式。例: 3件目のクラスなら「1-03-01」)で行う
- 削除したクラスの番号は再利用されず、欠番のまま次の番号が採番される

### 確認した環境
- [ ] Chrome (Mac)
