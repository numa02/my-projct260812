## TC-001: サインアップするとログイン状態になる(正常系)

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/auth-flow.spec.ts`(サインアップ→ログアウト→ログイン)

### 前提条件
- 未登録のメールアドレスを用意している

### 操作手順
1. `/signup` を開く
2. メールアドレス・パスワードを入力してサインアップを実行

### 期待結果
- 確認メールのクリック等なしに、そのままログイン状態になる
- クラス管理画面(`/classes`)に遷移する(初回セットアップフローの起点。`docs/design/user-flow.md`参照)

### 確認した環境
- [ ] Chrome (Mac)
