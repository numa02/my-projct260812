## 最低限のテスト(P0)

## TC-001: 未編集の場合は本ツール既定のひな形が表示される(空状態)

- 優先度: P0
- 種別: UI
- 観点: 空状態
- 自動テスト: `e2e/settings-prompt-template.spec.ts`

### 前提条件
- プロンプトひな形を一度も保存していないアカウント

### 操作手順
1. `/settings/prompt-template` を開く

### 期待結果
- 本ツール既定の初期値(`{{pseudonymCode}}`・`{{memos}}`等のプレースホルダーを含む)が表示される

### 確認した環境
- [ ] Chrome (Mac)

## TC-003: 編集して保存すると、以後の直接生成のプロンプトに反映される

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/settings-prompt-template.spec.ts`(`page.route()`でリクエストボディのプロンプト内容を検証)

### 前提条件
- APIキー設定済み。対象生徒に送信可能なメモがある

### 操作手順
1. プロンプトひな形を編集して保存する
2. 所感管理画面で対象期間を指定し、生徒の行のAI生成セクションで生成を実行する

### 期待結果
- AIプロバイダへのリクエストに含まれるプロンプトが、保存したひな形の内容をもとに組み立てられている

### 確認した環境
- [ ] Chrome (Mac)

## 後で確認するテスト(P1〜P3)

## TC-101: プレースホルダーを含まないひな形を保存した場合の挙動

- 優先度: P1
- 種別: 機能
- 観点: エッジケース
- 自動テスト: 未対応(手動確認)

### 前提条件
- `/settings/prompt-template` を開いている

### 操作手順
1. `{{pseudonymCode}}`等のプレースホルダーを一切含まない固定文言のみを保存する

### 期待結果
- エラーにならず保存できる(プレースホルダーが存在しない場合、置換は単に発生しないだけ)。生成されるプロンプトが固定文言のままになることを確認する

### 確認した環境
- [ ] Chrome (Mac)
