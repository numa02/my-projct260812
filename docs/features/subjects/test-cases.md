## TC-001: 科目を登録・編集・削除できる(正常系)

- 優先度: P0
- 種別: 機能
- 観点: 正常系
- 自動テスト: `e2e/subjects.spec.ts`

### 前提条件
- ログイン済み、科目0件

### 操作手順
1. `/subjects` を開く(「まだ科目が登録されていません」が表示されることを確認)
2. 科目名「国語」を登録する
3. 「国語」を「現代文」に編集する
4. 「現代文」を削除する

### 期待結果
- 各操作後にトースト(「科目を登録しました」等)が表示される
- 一覧に登録・編集内容が反映される
- 削除後は再び空状態の表示に戻る

### 確認した環境
- [ ] Chrome (Mac)
