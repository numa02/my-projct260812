## TC-009: 「追加する」を連打(同時に2回実行)しても科目が二重登録されない(エッジケース)

- 優先度: P0
- 種別: セキュリティ/データ整合性
- 観点: エッジケース
- 自動テスト: `tests/db/rpc-subject.test.ts`(`Promise.all`で2並列呼び出しを検証)

### 操作手順
1. `/subjects`で「追加する」ボタンを実行中の状態(`loading`)で連打を試みる
2. RPCレベルでも、`Promise.all`で同一教員が`seed_standard_subjects`を2回同時に呼び出すケースを確認する

### 期待結果
- フロント側は`loading`中ボタンが無効化され連打自体ができない
- 仮にサーバー側に2つのリクエストが同時に届いても、`pg_advisory_xact_lock`による直列化により最終的な科目数は10件(または11件)ちょうどになり、重複登録されない

### 確認した環境
- [ ] Chrome (Mac)

## TC-017: フィーチャーフラグON/OFFの挙動(段階リリース)

- 優先度: 該当なし
- 種別: 該当なし
- 観点: 段階リリース

**該当なし。** 本機能はフィーチャーフラグを導入しない(`docs/features/subjects/design.md`「段階リリース戦略」参照)。理由: 新設する`seed_standard_subjects`関数は既存データ・既存フローに一切触れない加算的な変更であり、フラグによる段階公開の必要性がない。
