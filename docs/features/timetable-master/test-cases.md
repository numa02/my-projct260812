## TC-022: フィーチャーフラグON/OFFの挙動(段階リリース)

- 優先度: 該当なし
- 種別: 該当なし
- 観点: 段階リリース

**該当なし。** 本機能はフィーチャーフラグを導入しない(`docs/features/timetable-master/design.md`「段階リリース戦略」参照)。理由: 新規テーブル・新規カラムを伴わない加算的な変更であり、既存のグリッド手入力機能への影響がないため、フラグによる段階公開の必要性がない。通常のmainマージ→Vercel自動デプロイで一括リリースする。

- 優先度: 該当なし
- 種別: 該当なし
