# 要件定義: 時間割マスタ CSV/貼り付け取り込み

`docs/requirements.md` F4(時間割マスタ設定)を拡張する追加機能。既存のグリッド手入力は変更しない。

## 機能概要

時間割マスタ設定画面(F4)に、CSVファイルのアップロードまたはテキストの貼り付けによって、時間割マスタの30マス(曜日5×時限6)を一括入力する機能を追加する。既存のグリッド手入力UIはそのまま残し、取り込み結果はグリッドに反映されたうえで、既存の保存ボタン・上書き確認ダイアログを経由して保存される。

## ユーザーストーリー

1. 教員として、時間割マスタの30マスを表計算ソフトで作成したCSVから一括で入力したい。それはマスを1つずつクリックして選択する手間を省くためだ。
2. 教員として、他の教員から共有された時間割の文字列をコピーして貼り付けるだけで時間割マスタを設定したい。それはファイルを経由せずに素早く反映するためだ。

## 機能要件

### 対象モードと列構成

- Given: 一括モードで時間割マスタ設定画面を開いている
  When: 「曜日,時限,科目名」の3列・ヘッダー行1行・30データ行のCSVをアップロードまたは貼り付けて取り込みを実行する
  Then: 30マスすべての科目がCSVの内容で`draftSlots`に反映され、既存のグリッド表示にも即座に反映される。クラスは画面上部で選択中のクラスが引き続き全マスに適用される(CSVにクラス列は含まれない)

- Given: 教科担任制モードで時間割マスタ設定画面を開いている
  When: 「曜日,時限,科目名,クラス名」の4列・ヘッダー行1行・30データ行のCSVをアップロードまたは貼り付けて取り込みを実行する
  Then: 30マスすべての科目・クラスがCSVの内容で`draftSlots`に反映され、既存のグリッド表示(マスごとに科目・クラスの2つの選択欄)にも即座に反映される

- Given: 一括モードでCSVに4列(クラス名列を含む)のデータを取り込もうとする
  When: 取り込みを実行する
  Then: 「一括モードでは科目名の3列形式のみ取り込めます」というエラーを表示し、取り込みを行わない

### 全か無か方式(既存のマスタ保存と同じ挙動)

- Given: 取り込もうとしているCSV・貼り付けテキストの科目名またはクラス名が、登録済みの科目一覧・クラス一覧のいずれとも完全一致しない行が1行でもある
  When: 取り込みを実行する
  Then: 該当行を含むエラー一覧が画面に表示され、`draftSlots`・グリッド表示は一切変更されない(1行もマスタへ反映されない)

- Given: 取り込もうとしているCSV・貼り付けテキストが30行に満たない、または31行以上ある(ヘッダー行を除く)
  When: 取り込みを実行する
  Then: 「30マス(曜日5日×時限6)分のデータが必要です」というエラーが表示され、`draftSlots`は変更されない

- Given: 取り込もうとしているCSV・貼り付けテキストの中に、同じ曜日・時限の組み合わせを指定する行が2行以上ある
  When: 取り込みを実行する
  Then: 「(曜日)曜(時限)限が重複しています」というエラーが表示され、`draftSlots`は変更されない

- Given: 30マスすべてが過不足なく揃い、かつ全行の科目名・クラス名が既存データと一致するCSV・貼り付けテキストである
  When: 取り込みを実行する
  Then: 30マスすべてが`draftSlots`に反映され、グリッド表示が取り込んだ内容に更新される。この時点ではまだDBへの保存は行われない(既存の「保存」ボタンを押すまでは確定しない)

### 保存フロー(既存フローの再利用)

- Given: CSV・貼り付けの取り込みによって`draftSlots`が更新された状態である
  When: 画面下部の既存の「保存」ボタンを押す
  Then: 既存のグリッド手入力時と全く同じ保存処理(`save_timetable_master`RPC呼び出し)が実行される。マスごとに異なるクラスが設定されている状態から一括モードで保存しようとした場合は、既存の上書き確認ダイアログ(「マスごとのクラス設定を統一しますか」)がCSV取り込み経由でも同様に表示される

## 非機能要件

- **パフォーマンス**: 既存の`save_timetable_master`RPCをそのまま呼び出すため、保存時のパフォーマンス特性は既存のグリッド手入力と同一。CSVパース・名前解決はクライアント側の同期処理で完結し、30行程度のデータ量であるため体感可能な遅延は生じない
- **既存機能への影響**: 既存のグリッド手入力UI・一括モード/教科担任制モードの切り替え・起算日入力・年度更新確認ダイアログは変更しない
- **認証・認可**: 既存のRLS(`teacher_id = auth.uid()`)をそのまま適用する。新規の認可ロジックは追加しない
- **ダウンタイム**: 本機能のリリースにダウンタイムは発生しない(DBスキーマ変更を伴わない)
- **ロールバック**: コードのデプロイを前バージョンに戻すことで完全に復旧する。DB状態への変更を伴わないため、データのロールバックは不要

## スコープ外

- CSVの科目名・クラス名の表記ゆれ吸収(全角/半角、大文字小文字の正規化)は行わない。前後の空白文字のトリミングのみ行い、それ以外は完全一致とする
- 取り込み結果のUndo(取り込み前の状態への復帰)機能は設ける。ページを離脱せずに取り消したい場合は、既存のグリッドを手動で編集し直す
- 部分成功(有効な行だけ反映しエラー行のみ除外する)方式は採用しない。全か無か方式のみ提供する
- 曜日の数値表記(1〜5等)や英語表記(Mon〜Fri等)の受け付けは行わない。「月」「火」「水」「木」「金」の漢字1文字表記のみを受け付ける
- CSVのテンプレートファイルのダウンロード機能は今回のスコープに含めない

## 用語

| 用語 | 定義 |
|---|---|
| 全か無か方式 | CSV・貼り付けテキストに1件でもエラーがある場合、取り込み処理全体を中止し、`draftSlots`を一切変更しない方式。既存の`save_timetable_master`RPCの保存挙動と同じ考え方 |
| 名前解決 | CSV・貼り付けテキスト中の科目名・クラス名の文字列を、登録済みの科目一覧・クラス一覧の`id`に変換する処理。完全一致(前後空白のトリミングのみ許容)で照合する |
