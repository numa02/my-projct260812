# デザインシステム:週間時間割・生徒メモ・所感自動生成ツール

`docs/design/design-principles.md` の方針(シンプル・静か・信頼感、Notion/craft.do路線)に基づくトークン定義。
未定の項目は「未定」と明記する。

## カラーパレット

### Primary

**未定**。ブランドカラー・ロゴが未確定のため。

- 方向性メモ: デザイン原則(静か・信頼感)に沿い、彩度を抑えた寒色系(青系)を軸とする案を検討中。決定後、この節に具体的なトークン値(50〜900等のスケール)を定義する

### Secondary

**未定**。Primaryが決まった後、補助的に使う色として検討する(使う場面が少なければ無理に定義しない)。

### Accent

**未定**。Primaryとは別に、強調・ハイライト用の色が必要かは画面設計(STEP 10〜11)を進めながら判断する。

### グレースケール

ブランドカラーに依存しないため先行して定義。

| トークン | 値 | 用途 |
|---|---|---|
| `gray-50` | `#F8F9FA` | ページ背景 |
| `gray-100` | `#F1F3F5` | セクション背景、ホバー時の背景 |
| `gray-200` | `#E9ECEF` | ボーダー、区切り線 |
| `gray-300` | `#DEE2E6` | 非活性ボーダー |
| `gray-400` | `#ADB5BD` | プレースホルダー、非活性テキスト |
| `gray-500` | `#868E96` | 補助テキスト |
| `gray-600` | `#495057` | 本文テキスト(サブ) |
| `gray-700` | `#343A40` | 本文テキスト(メイン) |
| `gray-900` | `#212529` | 見出し、強調テキスト |

### 状態色

ブランドカラーに依存しない一般的な意味色として先行して定義。

| トークン | 値 | 用途 |
|---|---|---|
| `success-500` | `#2F9E5B` | 保存成功、完了表示 |
| `warning-500` | `#C97A1F` | 注意文(AI送信の注意など) |
| `error-500` | `#C0392B` | エラーメッセージ、削除確認 |

状態色は必ずテキスト・アイコンでも意味を補足し、色のみに依存しない(design-principlesのアクセシビリティ方針に従う)。

## タイポグラフィ

- **フォントファミリー**: システムフォント優先(読み込み速度・native感を重視。Notion/craft.doも同様の方針)
  ```
  -apple-system, BlinkMacSystemFont, "Hiragino Sans", "Noto Sans JP", "Yu Gothic UI", sans-serif
  ```
- **サイズスケール**(本文14px以上の原則に従う)

| トークン | サイズ | 用途 |
|---|---|---|
| `text-xs` | 12px | 補助ラベル、タイムスタンプ |
| `text-sm` | 14px | 本文(表内、リストなど密な箇所) |
| `text-base` | 16px | 本文標準 |
| `text-lg` | 18px | 所感文など、じっくり読む本文 |
| `text-xl` | 20px | セクション見出し |
| `text-2xl` | 24px | 画面タイトル |

- **行間**: 本文は1.6、所感文などまとまった文章は1.8(可読性優先の原則)
- **フォントウェイト**: 通常400、強調500〜600。太字(700)は多用しない(装飾よりも静けさを優先する原則)

## スペーシング

8pxベース。余白を優先する原則に従い、詰め込みすぎない。

| トークン | 値 |
|---|---|
| `space-1` | 4px |
| `space-2` | 8px |
| `space-3` | 12px |
| `space-4` | 16px |
| `space-6` | 24px |
| `space-8` | 32px |
| `space-12` | 48px |

## ボーダー半径

craft.doのような柔らかいカード表現を意識し、やや大きめの半径を使う。

| トークン | 値 | 用途 |
|---|---|---|
| `radius-sm` | 6px | 入力欄、小さいボタン |
| `radius-md` | 10px | カード、モーダル |
| `radius-lg` | 16px | 大きいパネル・セクション |

## シャドウ

強い影は使わず、静かな印象を保つ。

| トークン | 値 | 用途 |
|---|---|---|
| `shadow-sm` | `0 1px 2px rgba(33, 37, 41, 0.06)` | カード、入力欄のフォーカス |
| `shadow-md` | `0 4px 12px rgba(33, 37, 41, 0.08)` | モーダル、ドロップダウン |

## ブレークポイント

| トークン | 値 | 対象 |
|---|---|---|
| `breakpoint-mobile` | ― | **対象外**。要件定義書のスコープ外(スマートフォン非対応)のため定義しない |
| `breakpoint-tablet` | 768px以上 | タブレット(縦・横) |
| `breakpoint-desktop` | 1280px以上 | デスクトップPC |

## ダークモード

対応しない(design-principles.mdの方針通り、MVPではライトモードのみ)。

## タップ領域

タブレット操作を想定し、ボタン・入力欄などの操作可能要素は最小44×44px を目安にする(アクセシビリティ方針に従う)。
