# コンポーネント設計:週間時間割・生徒メモ・所感自動生成ツール

`docs/design/screens.md` の14画面から抽出した共通コンポーネント。`docs/design/design-system.md` のトークンに従う。

## Button

- **バリエーション**: Primary(保存・作成などの主操作)/ Secondary(キャンセル・戻るなどの副操作)/ Outline(モーダル内の補助操作)/ Danger(削除など破壊的操作)
- **サイズ**: sm(表内の行内操作)/ md(標準)/ lg(フォームの主要送信ボタン)
- **状態**: default / hover / active / disabled / loading(スピナー表示+押下不可)
- **使用箇所**: ほぼ全画面(ログイン、各種保存、削除確認、生成実行など)。授業記録画面では折りたたみリストの各行に小サイズのPrimaryボタンとして個別配置し、生徒ごとに独立して保存する
- **入力プロパティ**: `variant`, `size`, `disabled`, `loading`, `onClick`

## Input(テキスト入力)

- **バリエーション**: text / email / password / number / date / textarea(複数行、メモ・所感本文用)
- **状態**: default / focus / disabled / error(枠線+エラーメッセージ表示)
- **使用箇所**: ログイン・サインアップ、クラス名/科目名入力、メモ入力、所感編集、APIキー入力など
- **入力プロパティ**: `type`, `label`, `placeholder`, `error`, `disabled`, `value`, `onChange`

## Select(単一選択)

- **バリエーション**: 通常セレクト(科目、クラス、学年、AIプロバイダ、モデル) / セグメントコントロール(一括モード⇔教科担任制モード、日付順⇔教科別など、選択肢が2〜3個で常時見えていてほしい場合)
- **状態**: default / focus / disabled / empty(選択肢が0件、例:科目未登録時)
- **使用箇所**: クラス管理、科目選択、時間割マスタ設定、所感画面(AIプロバイダ・モデル、生成/履歴タブ共通)、生徒別メモ一覧の表示切替。生徒名簿・生徒別メモ一覧・所感画面の各画面では、画面内の生徒絞り込み専用のクラス選択としても使う(グローバルなクラス切替は存在しないため、各画面が個別に持つ。所感画面ではタブ間で選択状態を共有する)
- **入力プロパティ**: `options`, `value`, `onChange`, `disabled`, `emptyMessage`

## Toggle / Switch

- **バリエーション**: 共有区分(共有する/共有しない)専用の2択トグル
- **状態**: on(共有する、初期値) / off(共有しない) / disabled
- **使用箇所**: 授業記録画面のメモ入力欄、生徒別メモ一覧
- **入力プロパティ**: `checked`, `onChange`, `disabled`

## Table / List

- **バリエーション**: 表形式(デスクトップ:クラス一覧、生徒一覧、科目一覧) / カードリスト形式(タブレット:同上をカード化) / 折りたたみリスト(氏名など1行の要約のみを表示し、タップで行内に入力・操作エリアを展開する形式。授業記録画面の生徒一覧で使用)
- **状態**: default(データあり) / empty(EmptyStateを内包) / loading(スケルトン行、または折りたたみリストでは行単位のローディング) / expanded(折りたたみリストのみ:選択中の行が展開されている状態)
- **使用箇所**: クラス管理、生徒名簿、科目管理、生徒別メモ一覧、所感画面(履歴タブ)、授業記録(折りたたみリスト)
- **入力プロパティ**: `columns`, `rows`, `loading`, `emptyState`、折りたたみリストは `expandedRowId`, `onToggleRow` を追加で持つ
- **備考**: 折りたたみリストは各行が独立して展開・保存できることを前提とし、ある行の展開・保存操作が他の行の状態に影響してはならない
- **実装(T-048時点)**: 3バリエーションは見た目・DOM構造の差が大きいため、1コンポーネントではなく `Table`(表形式) / `CardList`(カードリスト形式) / `CollapsibleList`(折りたたみリスト)の3つの独立したコンポーネント(`components/ui/`)として実装した。`columns`/`rows`/`loading`/`emptyState`は共通、`CollapsibleList`のみ`renderSummary`/`renderExpanded`/`expandedRowId`/`onToggleRow`を持つ

## Card

- **バリエーション**: メモカード(生徒別メモ一覧) / 所感カード(所感画面・履歴タブ) / 情報カード(ダッシュボード的要素があれば)
- **状態**: default / hover(クリック可能な場合) / selected(所感画面の履歴タブで選択中の期間)
- **使用箇所**: 生徒別メモ一覧(カードリスト表示時)、所感画面(履歴タブ)
- **入力プロパティ**: `title`, `meta`(日付・時限・科目・共有区分など), `body`, `selected`, `onClick`
- **備考**: craft.do路線に沿い、`shadow-sm` + `radius-md` の柔らかい表現を使う

## Modal

- **バリエーション**: フォームモーダル(マス編集モーダルなど入力を伴うもの) / 確認ダイアログ(ConfirmDialog、削除・上書き・学年変更などYes/No判断を伴うもの)
- **状態**: default / loading(実行中は確定ボタンをローディング表示) 
- **使用箇所**: 週次時間割のマス編集、各種削除確認、上書き確認、学年変更確認、モード切替時のクラス統一確認、エクスポート前の注意確認
- **入力プロパティ**: `title`, `body`, `confirmLabel`, `cancelLabel`, `variant`(通常 / danger), `onConfirm`, `onCancel`

## InlineMessage(注意文・警告文)

- **バリエーション**: info(AI送信に関する注意文など、通常の情報提示) / warning(注意喚起。例:共有区分を後から変更した際の「過去にAIへ送信済みの内容そのものは取り消せません」)
- **状態**: 常時表示(トースト等と異なり自動で消えない。「毎回表示する」という要件があるため)
- **使用箇所**: メモ保存時の「本文に書いた氏名等の情報はそのままAIへ送信されます」、所感画面(生成タブ)初回の仮名化注意文、エクスポート前の個人情報注意文
- **入力プロパティ**: `variant`, `message`

## Toast(一時通知)

- **バリエーション**: success(保存成功) / error(保存失敗)
- **状態**: 表示 → 数秒後に自動的に消える
- **使用箇所**: 各種保存操作の結果フィードバック全般
- **入力プロパティ**: `variant`, `message`, `duration`

## EmptyState

- **バリエーション**: 案内文のみ / 案内文+主要導線ボタン付き(例:「まだクラスがありません」+「クラスを作成」ボタン)
- **状態**: 該当なし(常に静的表示)
- **使用箇所**: クラス管理(クラス0件)、生徒名簿(クラス0件・生徒0件)、生徒別メモ一覧(メモ0件)、所感画面(履歴タブ:所感0件、生成タブ:送信可能なメモ0件)、科目管理(科目0件)
- **入力プロパティ**: `message`, `actionLabel`, `onAction`

## LoadingSpinner / Skeleton

- **バリエーション**: インラインスピナー(ボタン内) / スケルトン(一覧・カードの読み込み中プレースホルダー) / フルスクリーンローディング(AI生成待ちなど時間のかかる処理)
- **状態**: 該当なし
- **使用箇所**: 全画面のデータ取得中・保存中・所感画面(生成タブ)の待機中
- **入力プロパティ**: `size`, `label`(所感画面の生成タブのように待機時間が長い場合は状況を示すラベルを表示)

## Badge / Tag

- **バリエーション**: 共有区分バッジ(共有する/共有しない) / 作成方法バッジ(直接生成/プロンプトコピー運用/手動作成) / 「変更あり」バッジ(週次時間割の個別変更マス) / 「入力済み」インジケーター(ドット+ラベル。授業記録画面の折りたたみリストで、その日・時限に既にメモが保存済みの生徒の行に表示)
- **状態**: 色分けのみでなくラベルテキストを必ず併記(アクセシビリティ方針)
- **使用箇所**: 授業記録、生徒別メモ一覧、週次時間割、所感画面(履歴タブ)
- **入力プロパティ**: `variant`, `label`

## PasteOrUploadArea(CSV取り込み欄)

- **バリエーション**: ファイルアップロード / テキスト貼り付け(同一画面内でタブまたは併記)
- **状態**: default / dragover / エラー行あり(取り込み結果にエラー一覧を表示)
- **使用箇所**: 生徒名簿画面のインポート
- **入力プロパティ**: `onImport`, `errorRows`
- **実装**: `errorRows`の各要素は `{ rowIndex, reason, attendanceNumber?, name? }`。`reason`は`import_students` RPC(design.md §4.4)が返す`MISSING_FIELD` / `DUPLICATE_IN_BATCH` / `DUPLICATE_EXISTING`とそのまま対応させ、コンポーネント側で日本語文言に変換して表示する

## TimetableGrid(時間割グリッド)

- **バリエーション**: 編集モード(時間割マスタ設定画面) / 閲覧・個別編集モード(週次時間割画面)
- **状態**: 各マス単位で default / 未設定(空きコマ) / 個別変更あり(週次時間割のみ、Badgeを併用)
- **使用箇所**: 時間割マスタ設定画面、週次時間割画面
- **入力プロパティ**: `mode`(一括/教科担任制、または閲覧/個別編集)、`cells`, `onCellClick`
- **備考**: 2画面で見た目を共通化し、教員が同じ操作感で扱えるようにする

## CodeBadge(仮名コード表示)

- **バリエーション**: 通常表示のみ(氏名に併記する小さいラベル)
- **状態**: 該当なし
- **使用箇所**: 生徒名簿、所感画面(生成タブ、仮名コード確認)
- **入力プロパティ**: `code`

## Header / GlobalNav

- **バリエーション**: 該当なし(単一構成)
- **状態**: 現在の画面に対応するナビゲーション項目をハイライト表示
- **使用箇所**: 全画面共通
- **入力プロパティ**: `navItems`
- **備考**: グローバルな「選択中のクラス」は持たない(学級担任制・教科担任制どちらの教員にも対応するため。クラスに紐づく画面は各画面内で個別にクラスを選択する、`docs/requirements.md` F1参照)。画面全体の高さに固定されたサイドバーとして実装し、メインコンテンツ領域とは独立にスクロールする(サイドバー自体の中身がビューポートに収まらない場合のみサイドバー内でスクロールする)。メインコンテンツをどれだけスクロールしても、ナビゲーション・ログアウトは常に同じ位置に表示され続ける
